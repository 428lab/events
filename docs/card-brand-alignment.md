# プロフィールカードのブランド表示位置 (#505)

SVGロゴは64×64の枠に対して実際の描画範囲がy=12.9〜55.2にある。
枠をy=44へ置く従来配置では、1.35倍した図形の中心が約89.97になり、
同梱フォントの「EVENTS LAB」の大文字の中心（約69.61）より約20下だった。

文字を下げるとシリアル等の既存の文字配置まで崩すため、ロゴの配置だけを
y=24へ20上げる。横位置、サイズ、文字、アバター、QR、透かしは変えない。
共通のLicenseCardSvgを直すため、画面と印刷・画像書き出しで同じ配置になる。

## 確認

同梱Plus Jakarta Sans 700の読み込みを待ち、ブラウザで文字のインク範囲と
ロゴの描画範囲の中心差を測る。修正前は約20.36で1単位以内の検証に失敗し、
修正後はスマホ390px/PC1106pxとも約0.36になった。
実SVGに同梱フォントを埋め込んだPNGでも、描画ピクセルの中心差は0.5pxだった。
関連する既存のSVG・名札印刷テストで他の要素への回帰を確認する。
