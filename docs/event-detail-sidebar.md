# イベント詳細の右列のスクロール境界

## 制約 (#497)

デスクトップの右列はstickyで画面高に収める一方、参加者数や名前の折り返し、
運営招待の有無で内容の高さは変わる。最後の参加者の操作まで到達できなければならない。
モバイルでは高さを制限せず、ページ全体の通常スクロールを使う。

## 判断

スクロールの所有者は右列であり、内部の各カードではない。
MUI Cardはoverflow:hiddenを持つため、縦flexの既定値flex-shrink:1のまま
高さ制限のある列に置くと、内容を抱えたままカードだけが縮む。
その結果、列のスクロールでは隠れた参加者に到達できない。

EventDetailSidebarで直接の子の縮小を禁止する。カードの自然な高さを維持し、
列のoverflow-y:autoが余った高さを引き受ける。カードごとのスクロールや
人数制限は導入せず、参加者カードや招待カードの別画面での表示も変更しない。

## 検証の境界

単体テストは実際のMUI Cardにflex-shrink:0が適用される契約を検証する。
jsdomにはレイアウト計算がないため、画面幅・高さとスクロール到達性は
実ブラウザで別に検証する。修正の縮小禁止を外した変異でも比較する。
