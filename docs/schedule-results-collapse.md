# 日程調整結果の初期折り畳み (#509)

日程確定後の結果が普段の操作を押し下げないよう、`finalized` の場合は
主催側・参加者側とも見出しを残した初期折り畳みにする（オーナーの追加依頼で公開中にも拡大）。
見出しから結果を開け、スタッフは公開設定も操作できる。

ネイティブのdetails/summaryを使い、キーボード操作と開閉状態の支援技術への通知をブラウザーに任せる。
開閉状態は保存しない。同じ画面の再描画では開閉状態を保ち、イベント変更時にはリセットする。
調整中は従来どおり展開。結果非公開なら参加者には見出しも表示しない。API、保存データは変更しない。

関連UI検証5件で初期非表示→見出しから開閉→公開設定操作、公開中のスタッフ/参加者の折り畳み、調整中の展開、参加者の非表示を確認。
型検査を含むWebビルド成功。実機の受入確認はstagingで別途行う。本番は別承認。
