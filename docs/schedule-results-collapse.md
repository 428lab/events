# 非公開の日程調整結果の初期折り畳み (#509)

日程確定後、参加者への結果表示をOFFにしてもスタッフには設定操作のため結果が残る。
この結果が普段の主催操作を押し下げないよう、`finalized && isStaff && !visible` の場合だけ
見出しを残した初期折り畳みにする。見出しから結果と公開設定を開ける。

ネイティブのdetails/summaryを使い、キーボード操作と開閉状態の支援技術への通知をブラウザーに任せる。
開閉状態は保存しない。同じ画面の再描画では開閉状態を保ち、イベント変更時にはリセットする。
公開中・調整中は従来どおり展開。参加者に対する非公開条件、API、保存データは変更しない。

関連UI検証4件で初期非表示→見出しから開閉→公開設定操作、公開中/調整中の展開、参加者の非表示を確認。
型検査を含むWebビルド成功。実機の受入確認はstagingで別途行う。本番は別承認。
