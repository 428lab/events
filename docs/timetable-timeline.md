# タイムテーブル（広い画面）をタイムライン型にする

- 依頼: オーナー 2026-11-27。PR #711（トラックを列に並べた格子）をステージングで見て
  「あんま見栄え変わってない。メイントラックのコンテンツは灰色になってるし、それぞれが詰まりすぎてて見づらい。
  このページのタイムテーブルを参考にしてみて。見やすいよ https://nostrasia.com」
- 対象: `apps/web/src/lib/timetableLayout.ts`（並べ方）、`apps/web/src/components/TimetableGrid.tsx`（描き方）、
  `apps/web/src/pages/EventTimetablePage.tsx`（凡例）。サーバー・データは変えない
- スマホ（md 未満）のトラックのタブ（`TimetableTrackTabs`）と、イベント詳細の一覧（`EventSchedule`）は変えない

## 参考にした形（nostrasia.com のタイムテーブル）

同じ Nostrasia 2026 のタイムテーブルを、イベントのサイトでは次の形で出している。

- **縦のタイムライン**。左に開始時刻、その右に縦の線と丸。行は **コマの始まる時刻** ごとで、時間の長さに比例させない
- **カード**。左の太い線がトラックの色。題名が太く大きい。登壇なら「名前＋発表の題名」。場所の札（トラック名）
- **並行して長く続く企画**（フリーマーケット・ボードゲーム・交流スペース）は、右の**等幅の列**に横書きのカード。
  本筋の登壇は、その時間に空いている列のぶんまで広がる（Nostrasia なら 3列 → 2列 → 1列 → 3列）。
  縦書きの細い列は、向こうでも**スマホ（640px 以下）だけ**の見せ方
- 過去は薄く、開催中は強調、「いま」の位置に印

## 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 行 | どれかのコマが始まる時刻だけ（`layout.rows`）。行の高さは中身で決まる（`auto`）。行の間 14px | 5分の登壇が続いても潰れない。詰まりすぎない |
| 細い列に置くコマ | そのコマの最中に、**別のコマが2つ以上の時刻に**始まる（`TIMETABLE_SIDE_MIN_INNER_STARTS`） | 所要時間の長さではなく「並行して続くか」で決める。1つ重なるだけなら横に並べたほうが題名を読める |
| 並行の列 | **本筋と同じ幅**（`repeat(1 + sideLanes, minmax(0, 1fr))`）。中身は本筋と同じ**横書きのカード**（時間・題名・場所の札）。重ならないように番号を振る（0 が右端。早く始まった長い企画ほど右） | 2026-11-27 改め（下の「改めたこと」） |
| 本筋のカード | その行の範囲で空いている並行の列のぶんまで右へ広がる（`extendSide`。本筋のすぐ右の列から数える）。同じ時刻に重なるものは横に並べる (#345) | 長い企画が始まる前・終わった後は横幅いっぱい |
| 列の最小幅 | 1列 220px。これより狭い画面では横にスクロールする | 等幅の列で題名が細く折れすぎない |
| トラックの示し方 | 列ではなく、左の太い線と場所の札の色。凡例に色と名前 | 空のトラック（Lounge 2 など）が場所を取らない。#711 の「空のトラックも表示」の切り替えは要らなくなったので外した |
| 全トラック共通の色 | **テーマの主色**（`primary.main`）。場所の札は「全体」 | 灰色だと本筋の登壇が区切り線に見える（オーナー指摘） |
| 登壇者 | 小さな顔＋名前。説明があれば名前の隣に発表の題名（#693 の「登壇の題名が主」に合わせる） | 参考の「Main session 1 / kojira / The Potential of Nostr」と同じ読み方 |
| 時刻の状態 | 過去は薄く（0.45）、開催中は赤い枠と「開催中」、行の時刻を赤地に。「いま」は次に始まる行の上（最後のコマの最中なら末尾の下）に、時刻・ひし形・線 | 当日の会場で「今どこか」が分かる。1分ごとに setTimeout でつなぐ（ポーリングしない） |
| 日をまたぐイベント | 日の変わり目の時刻の上に日付 | 複数日の合宿でも読める |
| 色 | 線・紙の色はテーマのトークン（`text.primary`・`divider`・`background.paper`）。トラック色は今までどおり `trackColors.ts` | ピンク（sakura）でも暗い（natsumatsuri）でも同じ作りで読める |

残したもの: 7日の窓（打ち間違いを一覧へ落とす #346）、時刻未定・範囲外・未割り当ての一覧、裏方 (#383) の破線と鍵の印、
`role="region"` と横スクロールへのフォーカス。

## 実機の確認

本番の Nostrasia のタイムテーブル（18コマ・4トラック）を手元に写して、1600・1280・390、sakura と natsumatsuri で前後を撮った
（PR 本文に添付）。390 のスマホの表示は前と画像が一致（変わっていない）。

## 改めたこと（2026-11-27）

最初の版（#712）は、並行の企画を幅 52px の縦書きの細い列に置いた。オーナーがステージングを PC で見て
「PCの画面サイズでみた？縦書きはスマホ向けだよ」。nostrasia.com の CSS を見直すと、縦書き
（`.tt-card.narrow { writing-mode: vertical-rl }`）は `@media (max-width: 640px)` の中だけで、
広い画面では **3つの等幅の列**（`repeat(3, minmax(0,1fr))`）に、並行の企画も横書きの普通のカードとして置いていた。

そこで広い画面は縦書きをやめ、並行の列を本筋と同じ幅にして、中身も本筋と同じカードにした。
本筋の登壇は、空いている列のぶんまで広がる（Nostrasia なら 開場〜13:25 は3列、フリマの最中は2列、
交流スペース・ボードゲームも始まったら1列、マジックショーでまた3列）。
スマホ（md 未満）はトラックのタブのままなので、縦書きはどこにも使っていない。
