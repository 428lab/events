# イベント用カードエディター (#506)

## 承認済みの範囲

主催者がテンプレートを起点にパーツを選択・配置し、イベント専用に保存して、
実参加者のプレビューから一括印刷まで使えるようにする。
背景画像・コミュニティロゴ、名前・アバター・役割・参加枠・QR等を対象とする。
個人カードの設定とOG画像は変更しない。本番配備は別承認。

## 保存形式と優先順

バージョン付きの型付きJSONを保存する。HTML/SVG/CSS文字列や任意の外部URLは受け付けない。
座標は1074×650のカード空間で保持し、表示倍率や印刷画面の幅に依存させない。
初期テンプレートは名前重視・プロフィール交流・役割重視の3種で、いずれも編集可能なパーツ。

共通→現在の参加枠→スタッフの順で差分を適用する。差分は変更したパーツを置換し、
未変更パーツは共通設定に追従する。削除はIDの非表示指定として保持する。
最大40パーツ、32参加枠ルール、文書128KiBで入力と描画量を制限する。
QRの正方形・不透明性・最低サイズ・前面パーツとの重なり、カード外へのはみ出しを保存時にも検査する。

## 権限と競合

既存名札APIの「そのイベントの参加確定スタッフ」という境界を共有する。
サイト管理者やコミュニティ管理者だからという理由で編集・画像閲覧は許可しない。
イベントデザイン未設定はrevision=0/design=nullで表現し、従来印刷へのフォールバックを残す。

DBの条件付き更新で世代を比較し、競合は409を返す。文書と画像参照を同じbatchで保存する。
勝った更新の画像参照を負けたリクエストが消さないよう、更新ごとにランダムなトークンを使う。
画像参照にはイベントを含む複合外部キーを置き、事前照合後の削除競合でもトランザクションを戻す。

## 画像

イベント専用のR2キーとDBメタデータを持つ。PNG/JPEG/WebPのみ、5MiB以下、
各辺8192px以下かつ2400万画素以下。ヘッダー検証は完全なデコードではなく、
編集画面でのデコード確認も必要。SVGや任意外部URL取得は許可しない。

イベント当たり64画像までをDBの条件付きINSERTで予約し、R2保存完了までreadyにしない。
画像はスタッフ認可を通してno-storeで配信する。使用中画像の削除をDBで拒否する。
単体削除・イベント削除は既存mediaCleanupの順序（DB→R2ベストエフォート）に合わせる。
保存途中の失敗でも後処理を試み、ストレージ障害時の残骸はログとイベント専用prefixで追える。
既存の孤立画像一括清掃は対象外。

## 描画・編集・印刷

エディターと印刷はEventCardSvgを共有し、クリップIDはカードごとに一意にする。
パーツの追加/削除/前後関係/移動/リサイズ、数値指定と中央配置、取り消し/やり直しを備える。
文字は横につぶさず、折り返しとサイズ調整で枠に収める。小さすぎる文字には警告を出す。
編集対象の表示と、参加枠・スタッフを合成した印刷プレビューを区別して案内する。

編集画面はカード専用の全幅行を上に取り、下段に「パーツ一覧｜パーツの設定」を並べる。
スマホでは下段も縦並びにする。パネルがカードの幅を奪わないようにし、保存座標や印刷面付けは変えない。
実ブラウザで、854pxの編集領域に対してカード幅852pxを確認。PC1400px/スマホ390pxで
パーツ選択・ドラッグ移動・取り消し・幅の数値変更、日本語/英語の横あふれなしを確認した。
グリッド間隔指定・吸着の追加要望は別途仕様確認待ちで、このレイアウト変更には含めない。

名札APIは現在の参加枠をイベント条件付きJOINで付加する。
イベント設定が有効なときだけ本人別テーマに優先し、未設定なら既存SVGのまま印刷する。
文書取得・全カード描画・画像・フォントが揃うまで印刷ボタンを無効にする。
ブラウザの直接印刷でも準備未完了のカードは隠して案内を出す。A4・10面の既存面付けは維持。

競合時は手元の編集を保持する。最新状態への読み直しには破棄確認を挟み、
取得が失敗したら編集を捨てない。画像ファイル削除は取り消し対象外で、別途確認を挟む。

別イベントからのコピーは、同じ環境内で両イベントの確定スタッフである場合だけ許可。
リクエスト予算・メモリを制限するため画像を1枚ずつ別リクエストで複製し、コピー先のIDへ差し替える。
参加枠は名前が一意に一致するものだけ対応付け、一致しない設定の除外を画面で通知する。
途中失敗時は複製済み画像の後処理を試みる。削除に失敗したものもコピー先の画像一覧から管理できる。
個人カード・コピー元デザイン・コピー元の画像には書き込まない。

## 文字パーツのフォント（追加承認）

イベント画像スタジオと同じ26書体を、同じカテゴリで選べる。選択肢の正本はsharedの
DISPLAY_FONTS。文字パーツの任意項目fontに許可リストのIDを保存し、未指定/defaultは従来どおり。
既存文書の移行やDBテーブル変更は不要。スタッフ/参加枠差分やコピーでもパーツと一緒に保持する。
個人カードのフォントやイベント画像スタジオの描画・読み込み方式は変えない。

選択された書体のCSSだけGoogle Fontsから取得し、@font-faceの必要な記述のみ取り込む。
フォントファイルはhttps://fonts.gstatic.comのURLに限定する。画像スタジオの限定文字
サブセットと混ざらない別名でFontFaceを登録する。人名や自由入力をtextクエリへ送らず、
FontFaceSet.loadのローカルな文字範囲選択で必要なサブセットを取得する。
書体にない字は従来のシステムフォント等にフォールバックする。
任意ファイルのアップロード・外部URLの指定は対象外。新しい書体の取得にはネット接続が必要。

読み込み後にCanvasの実文字幅で折り返しとサイズを計算する。
太さが1種類しかない書体では合成太字を使わず、太字操作を無効にする。
印刷は全員分の使用文字が読み込めるまで待ち、取得エラー/タイムアウト時は止める。
失敗時は別の書体を選ぶか、編集を保存してページを読み込み直す。

全26書体の実取得と横つぶれ/文字の上下の収まり、PC1440px/スマホ390pxでの選択・
保存・再読み込み・印刷、日本語/英語の横あふれなしを確認した。
ブラウザ検証の業務APIはモック、フォントは実配信を使用。保存の往復は別途Workers/D1テストで確認。
ブラウザの印刷PDFではDotGothic16/Dela Gothicの埋め込みと日本語テキストの保持を確認した。
検証中に固定ウェイトへの合成太字による潰れを見つけて無効化した。テスト側のMUI選択ラベル、
確認ダイアログの自動却下、未登録辞書キー/Testing Libraryの型エラーはそれぞれ修正した。
stagingのCIでは既存のアバター失敗テストが一度失敗。非同期マウント直後の
初期化effectと失敗イベントが競合しないよう、イベント発火前にReactの初期化を確定させた。
失敗時に画像要素が消えてイニシャルが残る検証は維持し、個人カードの実装は変更していない。
iPhoneの実ブラウザ・物理用紙での印刷は未検証。

参照: [Google Fonts CSS2](https://developers.google.com/fonts/docs/css2)、
[FontFaceSet.load](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/load)。

## 従来フォントの横伸び修正

所有者の画像比較で、イベント用のkojiraがプロフィールより横長に描かれる不具合を確認した。
従来フォントだけ文字数による概算幅をtextLength/spacingAndGlyphsへ指定しており、
自然な字幅に対し約1.39倍になっていた。26種類の選択フォントの検証だけではこの経路を検出できていなかった。

イベント用文字から強制幅指定を除去し、従来フォントも同梱フォントの準備を待って実幅で折り返す。
文字パーツのサイズ設定と個人プロフィールの実装は変更しない。
実ブラウザ1200px/390pxで、kojiraの幅÷文字サイズは修正前3.720、修正後2.67732、
プロフィール2.67717（丸め差）となることを確認。従来字体・明朝・Dela Gothicの長い日英混在名も
文字を失わず枠内で折り返す。強制幅の再導入を検出する既存印刷テストの検証も追加した。

## 現在の検証

保存・権限・同時更新・別イベント画像参照拒否・アップロード検査・使用中画像削除拒否・
イベント削除時の画像回収をWorkers/D1/R2環境で確認している。
初回の追加テストはR2の未消費ストリームで隔離ストレージ後処理に失敗したため、
存在確認をgetからheadへ変更して解消した。製品の画像配信ストリームは変更していない。
PC1440px/スマホ390pxの実ブラウザで、ドラッグ移動・数値指定・取り消し・背景画像の追加・
保存・スタッフ色分け・印刷プレビューを確認。描画したQRをデコードし、プロフィールURLとの一致を確認した。
英語表示では中央配置ボタンの横あふれを見つけて縦配置に修正し、両幅で解消を確認。
権限判定を別コピーで無効化すると、参加者/未確定スタッフ/サイト管理者/画像閲覧/コピー元権限の検証が失敗する。
物理用紙への印刷、実機の指による操作、所有者の受入確認は別途必要。本番は未反映。
